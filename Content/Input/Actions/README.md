# Enhanced Input Assets & Input Mapping Contexts

* `IMC_Default`: Standard gameplay context (Movement, Look, Combat, Clock, UI)
* `IMC_InteriorInvestigation`: Close-range inspection context (Examine, Rotate Clue, Annotate Ledger)
* `IA_Move`: 2D Vector (WASD / Left Stick)
* `IA_Look`: 2D Vector (Mouse / Right Stick)
* `IA_PrimaryAttack`: Digital Button (LMB / Gamepad Bottom)
* `IA_EchoStrike`: Digital Button (Q / Gamepad Right)
* `IA_PossibilityShift`: Digital Button (Space / Gamepad Left Shoulder)
* `IA_DodgeRoll`: Digital Button (Left Shift / Gamepad Left)
* `IA_Interact`: Digital Button (E / Gamepad Top)
* `IA_ToggleLedger`: Digital Button (Tab / Gamepad View/Back)
